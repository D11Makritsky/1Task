# HTML CSS верста

## Задача

- По шаблону в Figma сделать верстку одностраничного сайта
- Для разработки использовать расширение PixelPerfect
- В процессе разработки правильно использовать семантику тегов
- Поскольку в шаблоне нет адаптивного дизайна придумать на свое усмотрение,
  но учитывать удобство пользователя
- Легкие анимации тоже приветствуются
